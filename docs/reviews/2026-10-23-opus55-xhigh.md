## 추가 가설 확인

[재리뷰 원문](2026-10-23-opus55-xhigh-followup.md)은 열린 P0/P1이 없음을 확인했고,
추가 P2 N1/N2를 제시했습니다. 두 회귀는 `f86a745` 소스에서 실패하고 보완 후 통과했습니다.

- N1: GUI 선택 여부와 무관하게 실제 native 필터를 snapshot/clear/restore합니다. 전체 도구를 허용하는 프로필은 새 MCP 도구를 받고, 명시 목록 프로필은 기존 registry 전체를 나열했더라도 새 MCP 도구를 자동으로 얻지 않습니다. manage/slash 프로필 선택은 이전 GUI override를 해제하고 native 프로필에 위임합니다.
- N2: native가 아직 streaming이고 취소 상태이면 idle 대기 중 abort를 재전송합니다. `before_agent_start` barrier 이전에 취소하고 provider 응답을 계속 막은 실제 프로세스에서 prompt가 cancelled로 정리되는 것을 검사했습니다. 이 변경이 임의 native preflight 훅 자체의 강제 취소를 증명하지는 않습니다.

[제한 재검증](2026-10-23-opus55-xhigh-verification.md)은 N1/N2 주 경로의 해결과 P0/P1 부재를 확인했고,
새 P2 R1/R2를 발견했습니다. 두 항목을 다시 보완했습니다.

- R1: 반복 abort RPC의 hook 오류를 억제하되 authoritative get_state 오류·외부 취소·deadline은 전파합니다. 예외를 내는 abort hook의 실제 회귀가 통과했습니다.
- R2: 프로필의 live 필터를 GUI override로 저장하지 않습니다. 프로필의 `bash`를 제거한 뒤 다시 load하면 `read`만 남는 실제 회귀가 통과했습니다. 기존 명시적 GUI/slash 선택은 별개의 사용자 override입니다. 중간 보완 커밋에서 잘못 캐시된 프로필 목록은 프로필을 다시 선택해 해제할 수 있으며, 출처 없는 기존 사용자 선택을 임의로 삭제하지 않습니다.

[마지막 패치 확인](2026-10-23-opus55-xhigh-closure.md)은 제공한 R1/R2 코드·테스트 패치에 한정해
두 항목의 해결과 추가 구체적 회귀 부재를 확인했습니다. 이 실행은 도구를 비활성화한 제한 검토이며,
전체 소스 리뷰로 계산하지 않습니다. 원문 말미의 ExitPlanMode 표기는 실행된 도구 호출이 아닙니다.
부모가 grep으로 확인한 sync_profile_tools 호출처는 manage/slash의 agents/use 두 곳뿐이고,
profile_uses_all_tools는 configure_mcp에서 실제 사용합니다.
[실행 메타데이터](evidence/2026-10-23-review-runs.json)에 각 범위·model·effort·도구 수를 기록했습니다.

- delete/load 경쟁은 추가 재현으로 확인했습니다. 삭제 동안 actor 예약·mutation lock·OS lease를 유지하고, load는 lease 아래에서 index를 재확인합니다. 삭제 중 새 prompt/load를 거부하는 회귀가 통과했습니다.
- 생성자와 lease 획득 사이에 실행 설정이 바뀌는 경우를 보강했습니다. 실제 자식 argv가 최신 trust·delegation 설정을 사용하는지 검사했습니다.
- 재시작은 OS lease를 유지합니다. 이 변경이 Windows 파일 시스템의 모든 잠금 지연을 증명하는 것은 아닙니다.
- client JSON-RPC 오류를 invalid parameter로 분류하던 부분은 backend outcome으로 바꿨습니다. 부작용이 있을 수 있는 결과를 확정적인 입력 거부로 기록하지 않습니다.
- branch 후 auto-compaction/auto-retry 토글 손실은 pinned native에서 재현되지 않았습니다. 실제 clone 후 두 false 값이 유지됐고 이 가설 때문에 코드를 바꾸지 않았습니다.
- stderr를 읽지 않는 클라이언트의 장기 진행, 별도 사용자 정의 delegated-child 확장 상속, binary blob resource 의미, native preflight cancellation은 원본 가설과 문서화된 한계로 남깁니다. 검증된 수정으로 계산하지 않습니다.
- MCP 하나가 실패하면 전체 구성을 거부하는 동작과 offline/extension/sandbox 범위는 기존 선택입니다. 코드 리뷰가 이 선택을 현장 수용 검증으로 바꾸지는 않습니다.
